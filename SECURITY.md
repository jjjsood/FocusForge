# Security Policy

## Supported versions

Before the first release, security fixes are prepared for the current
unreleased version. After releases begin, fixes are provided for the latest
release.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub private vulnerability
reporting](https://github.com/jjjsood/FocusForge/security/advisories/new).
Include a clear description, affected version, reproduction steps, and any
relevant logs or diagnostics bundle. Do not open a public issue for a
vulnerability.

We will acknowledge the report and coordinate disclosure with the reporter.
The investigation and release timing depend on the issue's impact and the
availability of a safe fix.
