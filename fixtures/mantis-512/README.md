# Fixture set `mantis-512`

Algorithm scale: eight evenly spaced frames, wide enough for a pyramid deep enough to matter and for alignment to have something to find.

Crop rect (x, y, w, h): **3840,2476,512,512** -- a 512x512 window taken from the same place in every frame.

Why this rect: Centred on the frame, spanning the focus sweep: the reference crop is 3.24x sharper (16-bit Laplacian variance) than the best single frame, with an 8-way per-tile winner map and a 28x max best/worst ratio -- different source frames win different tiles, which is the phenomenon a fusion fixture has to exercise.

`head64k_sha256` is the sha256 of each source frame's first 64 KiB, truncated to 16 hex characters. It pins the header and the leading strips; it is not a whole-file digest, because each source frame is 268 MB and hashing all 61 would read 16 GB to answer a provenance question.

`reference.tif` is the identical crop of `Mantis_Stacked.tif`, converted from big-endian to little-endian and to one strip per row like every other file here.
