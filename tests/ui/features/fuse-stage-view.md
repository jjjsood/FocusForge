# Fuse stage view
Reach: open `fixtures/mantis-512/frames` and `fixtures/mantis-64/frames` with `Start: --open … --open … --slow-run 1 --slow-run-seconds 600`, then press **Fuse stack** (`FFToolbar::fuse-button`) on the first tab. While a run is going the Composite pane (the right pane) shows what the run is doing instead of its "Not fused yet" card.
Sub-features: the card before a run ("Not fused yet"), the stage card while a run is held ("Fusing"), the same card through pause and resume, the other tab keeping its own card, the Composite pane in its own window showing the stage card, cancel bringing "Not fused yet" back, discard and keep ending the view, a fuse over a kept result showing no card, the sharpness inset and tile grid of the growing result (human only).
Ids: launch options `--slow-run N` (hold the Nth run of the launch in its fuse stage) and `--slow-run-seconds S` (how long, default 150); the pane's cards `FFCanvas::pane-placeholder` ("Not fused yet" / "Fuse stack builds the composite here.") and `FFCanvas::stage-card` ("Preparing frames", "Alignment reused" or "Fusing"); the same card in the Composite window `ComparisonWindow::stage-card`; `FFUndockControl::area` 1 (undock the Composite pane; "Dock pane" is `FFUndockControl::area` 0 in the second window, `--window N`); `FFToolbar::pause-button`, `resume-button`, `cancel-button`; `FFBottomBar::status-text`, `step-text`, `eta-text`, `progress-bar`; the Settings window's Appearance row "Sharpness heatmap".
Gotchas:
- A held run stops before its first fuse tile is finished, so while it is held the pane shows the card "Fusing" ("The result builds here tile by tile.") and never a picture. The aligned frame, the result growing tile by tile with its grid and its "Sharpness" card, and the growth over an old composite pass in seconds once a run is not held; no step can catch them, so the journey lists them as `(human only)` steps.
- Alignment is not held. It runs before the hold and is served from the cache after the first run of a launch: the first run shows "Preparing frames" and then the pane label "Aligned · <name>.tif" over the aligned frame, a later run shows the card "Alignment reused" and no "Aligned · " label.
- The picture of the stage has no id; only its cards do. `FFCanvas::pane-placeholder` is hidden while a stage card or a stage picture shows, so "Not fused yet" and "Fusing" are never on screen together. Read both cards from a screenshot or with `find_elements_by_id`.
- Pause keeps the card; the other tab shows its own card ("Not fused yet", toolbar "Queued"). In the Composite window the main window's right pane is gone, so the card shows only there.
- The bottom bar keeps its status and progress bar during a run; no separate row of stage names appears. While the run is held before its first fuse tile the step text is hidden (`FFBottomBar::step-text` has no instance): the bar reads "Fusing", "estimating" and an empty progress track.
- A fuse over a kept result reuses the cached alignment and ends within seconds, so the Keep question may already cover the pane at the next screenshot; only the first run of a launch is held.
- A fuse over a kept result shows no card: the kept composite stays until the growing result covers it. After **Discard** the kept composite is still there; after **Discard** of a first fuse the pane reads "Not fused yet" again with no picture. Behind the Keep question the pane shows the finished result labelled "Composite".
- The "Sharpness heatmap" row (Settings window, Appearance) switches the sharpness inset off. No journey flips it: its effect shows only on the growing result, which no step can reach (see "Not covered yet" in the feature index).
- The run is held at its first fuse tile for `--slow-run-seconds` of running time (journey 20 sets 600: slower runners reach Cancel only after several minutes, and the default 150 s let the run finish into the Keep question first), pauses excluded; cancelling ends it at once.
