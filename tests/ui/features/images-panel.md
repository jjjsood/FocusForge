# Images panel
Reach: open a folder (`--open`); the **Images** tab (`FFDockTabs::images-tab`) of the right dock lists the frames. Needs the STACKING mode and no run in progress to change anything. After a fuse the window switches to the editor; click **STACKING** (`FFModeSwitch::stacking-half`) to edit the list again.
Sub-features: header text ("8 frames · 0 excluded"; "1 frame" in the singular; the editor shows "8 frames"), select a row, exclude and include (eye), remove (trash), sort menu (**Name** / **Capture time**, ✓ on the chosen one, cleared by a manual drag), drag-reorder by a row's file name or preview image, add frames (folder-plus icon), read-only legend in the editor, the three presentations (List, Image list, Large previews) picked under Settings > Appearance.
Ids: `FFImageRow::area` N (row N); per presentation the row's file name `FFImageRow::list-name-slot`, `image-list-name-slot`, `large-name-slot`, its **Exclude**/**Include** eye `FFImageRow::list-exclude-button`, `image-list-exclude-button`, `large-exclude-button` and its **Remove** trash `FFImageRow::list-remove-button`, `image-list-remove-button`, `large-remove-button`; the Large preview image `FFImageRow::large-identity`; header **Add images** `FFImagesPanel::add-button` and **Sort** `FFImagesPanel::sort-button`; the Appearance field **Presentation** `FFMenu::root`; `FFMenuList::option-area` 0 (Name) and 1 (Capture time), dialog `AppWindow::frame-warning`.
Gotchas:
- The eye and trash icons exist only on the row under the pointer, so each has exactly one match, number 0; clicking a row leaves the pointer on it, which is what brings them up. After a dialog button is clicked the pointer is elsewhere: click the row again first.
- Sort and add icons are absent, not greyed, in the editor and while a run is live; the panel dims while a run is live.
- Removing a frame before any checkpoint happens at once with no dialog. With a checkpoint, remove, sort, drag and add raise `AppWindow::frame-warning` ("Remove and fuse again?", buttons Cancel, "Exclude instead", "Remove and re-fuse"); Cancel changes nothing; confirming applies the change, re-fuses and ends in `AppWindow::divergence-warning`, then appends a second checkpoint (the first stays). Exclude is never gated.
- A default fuse of `fixtures/mantis-512` ends in the "Keep this fused result?" dialog; after **Keep** the window is in the editor.
- A manual drag clears the sort choice; picking **Name** again restores the file-name order. The sort menu closes when the sort button is pressed again.
- `--frame-remove-warning N` removes frame N right after open, before any checkpoint, so it removes at once with no warning; it only warns for a saved project. `--images-sort-menu-open` starts with the sort menu open.
- A fresh settings folder shows Image list (120 px rows), where an 8-frame list runs below the fold and the lower rows are absent from the tree; 10-images-panel.md switches to List first so every row is mounted. A row drag starts on the file name (List) or on the file name or preview image (Image list, Large previews); 13-source-image-views.md drives it in Large previews. A step after a human-only drag must not depend on it having happened (the sort check mark stays on "Name" without a drag and is cleared with one).
- Human only: dragging a row in List, the native file dialog behind the add icon, wheel scrolling the list, judging the frame thumbnails.
