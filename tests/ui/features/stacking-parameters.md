# Stacking parameters
Reach: open a folder (`--open`), then click **Settings** (`FFDockTabs::settings-tab`) in the right dock, or start with `--dock-tab settings`. The tabs are only shown in stacking mode with a project open.
Sub-features: four sections PREPARE, FUSE, ALIGN, FINISH, each with a "DEFAULT" badge until one of its values is set; **Reset All to Default** (greyed until a value is set); the algorithm menu under FUSE ("Details", "Soft transitions", "Focus map") and under ALIGN ("Pyramidal ECC"); **More...** fold-outs holding the advanced rows; the ALIGN **Enabled** switch; menu rows (ALIGN "Mode"); PREPARE's Equalize brightness switch with Max brightness gain and the signed Target brightness (stops) slider (keyboard steps, 0.1 snapping, the ±0.5 ends, values kept while the switch is off); settings kept separately per project tab; the panel locked while a fuse runs.
Ids: `FFMenu::root`, `FFMenuList::option-area`, `FFMoreToggle::header-area`, `FFToggle::area`, `FFSlider::drag-area`, `FFResetAll::area`, `FFScrollbar::track-area`, `FFTab::area`.
Gotchas:
- Row ids count only the controls inside the visible part of the panel: a row scrolled out of view is absent, and an open menu list counts only its own entries (`FFMenuList::option-area` 0 to 2 for the FUSE list, 0 and 1 for a Mode list, none while closed). Assumed state at launch: FUSE "Details", every More... closed, ALIGN enabled, panel scrolled to the top. Then `FFMenu::root` 0 is the FUSE Algorithm field and 1 the ALIGN one (an opened ALIGN More... adds Mode as 2); `FFToggle::area` 0 is ALIGN Enabled (an opened PREPARE More... puts "Equalize brightness" first); `FFMoreToggle::header-area` 0, 1, 2 are PREPARE, FUSE, ALIGN while all three are in view (an open fold-out pushes the headers below it out of view, so close a fold-out before using the next one); `FFSlider::drag-area` numbers the panel's sliders top to bottom, the bottom bar's overlay slider last. Scrolled to the end (ALIGN More... closed), `FFToggle::area` 0 is ALIGN Enabled, 1 is Auto-crop and 2 the overlay switch. Scrolled to the middle (`1193 480`, ALIGN More... open), `FFMenu::root` 0 is the ALIGN Algorithm field and 1 the Mode field.
- **Reset All to Default** and the rows below the fold are absent from the element tree until scrolled: there is no wheel, so drag `FFScrollbar::track-area` 0 to the bottom (`1193 705`), to the middle (`1193 480`) or back to the top (`1193 225`). The scroll position stays when another project tab is selected. Whether **Reset All to Default** is enabled is read with `buttons FFDock::settings-panel` (its line starts with `x` while it is disabled); the panel's switches, menus, More... bars and Reset All list there as buttons, and only rows inside the visible part are listed. The wheel scroll itself is human only.
- A slider is set by clicking the middle of its track (`FFSlider::drag-area`), which sets the half-way value: Radius 8 of 0 to 16, Sharp-source preference about 4.5 of 1 to 8. A value is typed with `Type` into the field; no journey does.
- Defaults seen at launch: FUSE "Details" has no row outside More... (only "Levels", whose default is derived from the image size); "Soft transitions" shows "Sharp-source preference" 4 and, under More..., "Radius" 16; "Focus map" has under More... "Score Radius" 4 and "Smoothing Radius" 8; PREPARE holds only More... ("Equalize brightness" on, "Max brightness gain" 1.25); ALIGN holds "Enabled", the "Algorithm" menu and More... ("Mode" Rotation + Scale, "Max Iterations" 400, "Epsilon (px)", "Pyramid Depth", "Reference Policy", "Reference Frame"); FINISH holds "Auto-crop" (on).
- Picking another algorithm changes no value, so it keeps the section at "DEFAULT"; **Reset All to Default** clears values but keeps the chosen algorithm. The open More... folds stay open after a reset and across an algorithm switch.
- A value set to what the default already is still counts as set: the badge stays gone.
- The ALIGN heading counts its **Enabled** switch: writing it, off or back on, removes the ALIGN badge and enables **Reset All to Default**; only Reset All brings the badge back. Greyed ALIGN rows are inert: clicks on them report success and change nothing.
- While a fuse runs the whole panel is dimmed and inert, and stays so while the run is paused. Journey 09 starts with `--slow-run 1`, which holds its first run in the fuse stage so steps 2-5 can pause it and click the ALIGN switch; Pause waits for the bottom bar to read "Fusing". The Equalize brightness switch exists only while PREPARE's More... is open (it is an advanced row), so with every More... closed `FFToggle::area` 0 is ALIGN Enabled and 1 is Auto-crop (steps 4, 8, 20, 22, 31).
- The FUSE picker lists exactly "Details", "Soft transitions" and "Focus map" in every build, so "Soft transitions" is option 1 and "Focus map" option 2; test-only algorithms never appear in it. The guide names the entries by their grey ids.
- Human only: the scroll wheel in the panel, judging that a changed parameter changes the fused pixels.
