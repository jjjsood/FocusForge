# Analytics
Reach: press the Analytics button in the icon bar on the left edge, directly under the step calculator button (label **Analytics**, inside `AppWindow::icon-bar`). It is never greyed out: with no project open it shows the waiting panel. The same button, **Close** (top right of the overlay) and Escape close it. `--open <folder> --analytics` opens it once the folder has loaded; `--analytics-hold-ms MS` holds each count back so the pending rows can be looked at.
Sub-features: one row per frame of the selected tab in the dock's order (chip, file name, bar, count; excluded frames are listed too); bar length is the count divided by the largest count, empty for every row when all counts are 0; no millimetre column without rail positions; the waiting panel "No stack loaded" / "Load a stack to count its sharp areas." without a project; while the count runs every row is listed with a sweeping bar and a spinner in place of its count (`pending`), then a growing fill with the spinner kept, then the final count; the count restarts for the newly selected tab; closing the overlay stops the count; one full-canvas overlay at a time (the projects overview, the notification center and the step calculator close it, and it closes them).
Ids: `AppWindow::icon-bar` (the button is clicked by its label), `AppWindow::analytics-overlay` (**Close** is clicked by label inside it).
Gotchas:
- The overlay covers the canvas only: the toolbar, the dock and the bottom bar stay visible. The window's title-bar button is also labelled "Close", so a Close step names `AppWindow::analytics-overlay`.
- Counts of `fixtures/mantis-512/frames` (00.tif to 07.tif): 0, 0, 4, 11, 0, 0, 0, 1. `fixtures/mantis-64/frames` counts 0 for all three frames.
- With the hold flag every opening shows the pending rows (sweep and spinner, no number) for the hold time; a step that reads rows says `(within 60 s)`.
- Not covered by the journey: the failed state (red "Counting failed" over the core message, no rows; a frame deleted after the folder was opened, reachable only by deleting a file during the hold), the partial fills (a single-tile fixture goes from pending straight to final; `--analytics-tile-size 96` with `--analytics-tile-pause-ms` makes them watchable), a list taller than the body with its scrollbar (needs a stack of more frames than fits, none is checked in, and the wheel is a human-only input), and the editor mode. Check them by hand with a copy of a fixture under `.scratch/`.
- Opening the overlay with a driver needs a build with the `mcp` feature (`tools/gui/run-gui.sh` builds it); a binary built without it answers no request.
