# Settings window
Reach: click the gear (`FFBottomBar::gear`) in the bottom bar. The window is `AppWindow::settings-modal`; its close button is `FFSettingsModal::close`; the rail entries are `FFNavRailEntry::area` N counting from 0 in the order Performance, Storage, Input map, Diagnostics, About (indices assumed from the rail's source order).
Sub-features: Performance (GPU processing switch, Backend line, Host memory cap, VRAM cap, Host and VRAM budgets), Storage (LOCATIONS paths, Clear cache), Input map (read-only BINDINGS table), Diagnostics (file list, Include minidumps switch and warning, Save to, Create bundle), About (version, license, notice, source), closing the window, the GPU switch persisting across close and reopen, the Backend line after a fuse with the switch off.
Gotchas: only the open section's content exists in the window, so `FFToggle::area` 1 is the one switch on screen (Performance GPU switch or Diagnostics minidumps switch; instance 0 is the bottom-bar Overlay toggle). The switches have no text: on is the knob at the right end on an accent track, off is the knob at the left end on a grey track. "Backend" is a text row, not a menu, and is empty until a fuse has run; after a fuse with the GPU switch off it reads "cpu — GPU processing is off". "VRAM budget" reads "Not probed yet" until a fuse with the GPU on has run. Host budget and the Version text vary by machine and build. The window covers the whole main window as a modal: a click on the toolbar behind it reports success but does nothing. The GPU switch is saved in the settings file under `--config-dir`. The log, crash, scratch and bundle locations come from the environment's data folder, not from `--config-dir`; **Clear cache** and **Create bundle** act on that folder, so a guide only looks at them and never presses them. Typing into the cap fields and "Save to" is human only, as is opening the "Source" link. No Esc binding was found for the window. The window is a fixed 680x520 panel with no scrollbar: every section fits in view (only the Diagnostics file list scrolls inside itself). The path texts under LOCATIONS and in "Save to" are cut off by their field width and start with "~/" or the config/data folder as given, so a guide asserts that a path text is shown, never its end; "not created yet" follows a folder that does not exist yet and varies by run. The Input map table has seven cells per column (`FFInputTableRow::input-cell` 0 is the header, 1 to 6 the rows).
